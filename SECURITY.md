# Security

Please report suspected vulnerabilities privately to **bblu@duck.com**, with “Vibeking security” in the subject. Include the affected version, impact, reproduction steps, and a minimal example where possible. Do not send API keys, private recordings, or unrelated personal data.

Please avoid publishing exploit details in a public issue before the report has been assessed. Regular bugs and feature requests belong in [GitHub Issues](https://github.com/bblurock/vibeking/issues).

See [Privacy](docs/privacy.md) for local API-key storage and optional cloud processing. Security fixes are distributed through [Releases](https://github.com/bblurock/vibeking/releases); this version has no built-in updater.
